Sistema web de **cadastro e login** desenvolvido como atividade prática da disciplina de **Teste de Software II**. O projeto aplica conceitos de testes de unidade, integração, UI, usabilidade e regressão em uma aplicação real.

---

## 📋 Sobre o Projeto

**GameHub** é uma plataforma fictícia onde gamers podem criar suas contas e fazer login para favoritar jogos. O sistema valida todos os dados inseridos e fornece feedback visual em tempo real.

### 🎯 Funcionalidades

- ✅ Cadastro de usuário (nickname, email, data de nascimento, jogo favorito, senha)
- ✅ Login com validação de credenciais
- ✅ Feedback visual com cores (verde = sucesso, vermelho = erro)
- ✅ Simulação de persistência usando `localStorage`
- ✅ Validação de campos com regex e regras de negócio
- ✅ Testes de unidade automáticos via `console.assert()`
